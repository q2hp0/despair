despair is a tool you use when you are tired of your project, when the project looks like complete garbage and you just want to get rid of it as fast as possible. no motivation, no fixing, no more pretending that the project will ever become something. just give despair a directory and let it deal with the remains. it is written in java because apparently even bad decisions need classes. it has no fancy interface and no personality settings. it just looks at your files and judges nothing. by default it only shows what it would remove. use --commit if you really want it gone. the main directory stays there, because even despair has some limits. you should it on your home directory or system folders. also there is a tiny go2js test somewhere outside this folder because why not. enjoy your questionable decisions.
